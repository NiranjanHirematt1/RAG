# DocuMind — RAG over your PDFs (Groq edition)

Chat with your PDF documents. Text is chunked and embedded locally, stored in
Qdrant, and answers are generated by a **Groq** LLM using only the retrieved
context.

## What changed from the original

- **OpenAI → Groq** for answering. Groq has **no embeddings endpoint**, so
  embeddings now run **locally** via `sentence-transformers`
  (`BAAI/bge-small-en-v1.5`, 384-dim) — free, no API key needed.
- All syntax/logic errors in `main.py` were fixed and the ingest + query
  Inngest functions were wired to a shared `rag_core` module.
- Qdrant runs **on-disk locally by default** (no server required). Set
  `QDRANT_URL` in `.env` to use a running Qdrant server instead.
- Added a polished **Streamlit** front-end (`app.py`).

## Setup

```bash
# 1. install deps (uv recommended, or pip)
uv sync           # or:  pip install -e .

# 2. your Groq key is already in .env
```

`.env` keys: `GROQ_API_KEY`, `GROQ_MODEL` (default `openai/gpt-oss-120b`),
`EMBED_MODEL`, `EMBED_DIM`, `QDRANT_URL` (blank = local), `QDRANT_PATH`.

> Note: `llama-3.3-70b-versatile` is being deprecated by Groq. Defaults use
> `openai/gpt-oss-120b`; you can switch to `openai/gpt-oss-20b` or
> `llama-3.1-8b-instant` in `.env`.

## Run the UI (easiest)

```bash
streamlit run app.py
```

Upload a PDF in the sidebar → **Add to knowledge base** → ask questions.
The first run downloads the small embedding model (~130 MB) once.

## Run the API service (optional, Inngest)

```bash
uvicorn main:app --reload
# in another terminal, start the Inngest dev server:
npx inngest-cli@latest dev
```

Trigger events `rag/ingest_pdf` ({"pdf_path": "...", "source_id": "..."}) and
`rag/query_pdf_ai` ({"question": "...", "top_k": 5}).

## Files

| File | Purpose |
|------|---------|
| `app.py` | Streamlit front-end |
| `rag_core.py` | Ingest + retrieve + Groq answer (shared core) |
| `data_loader.py` | PDF chunking + local embeddings |
| `qdrant_db.py` | Vector store (local or server) |
| `main.py` | FastAPI + Inngest functions |
| `custom_types.py` | Pydantic models |
